# Dust Runner controls

| Keys | Action |
| --- | --- |
| WASD / arrow keys | Drive; hold the brake after stopping to reverse in automatic mode |
| Shift / comma | Hold the handbrake / toggle the parking brake latch |
| Q / E / B | Shift down / shift up / select neutral in manual mode |
| 1 / 2 / 3 / 4 | Automatic / HI / LO / 4×4 crawl |
| Z / X / H | Front differential lock / rear differential lock / HDC |
| V | Cycle the view: cockpit, hood, chase, classic board |
| T | Cycle the time of day: morning, midday, golden hour, dusk, moonlit night |
| IJKL / +− / O | Board view: orbit camera / zoom / reset. Driver views: glance around / zoom / look ahead |
| [ / ] | Previous / next vehicle while driving |
| Space / R / period | Nitro / horn / start or stop the engine (stop the vehicle before switching off) |
| F / N / P | Recover / restart level / pause |

In the driver views you can also drag with the mouse to look around. The view holds while the button is down and returns to the road shortly after you let go.

On phones, use the touch controls. Drag the terrain to orbit the camera (or to look around from the driver's seat); pinch with two fingers to zoom. See [mobile controls](mobile-controls.md).
